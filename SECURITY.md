# Reporting security vulnerabilities

Please use GitHub's **Security > Advisories > Report a vulnerability** for a private report:

https://github.com/manuelemosr/localzie-connector/security/advisories/new

Do not open a public issue with exploit details, pairing codes, enrollment JWTs, identity files, private keys, device tokens, runtime credentials, or real conversation data.

Include the connector version/commit, operating system, affected configuration with secrets removed, attack prerequisites, impact and a minimal synthetic reproduction. See [the threat model](docs/security.md) for scope and known limitations.

## Supported versions

This project is a developer preview. Security fixes target the current `main` branch; no stable release or long-term support policy is promised yet.
